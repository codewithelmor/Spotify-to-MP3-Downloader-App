# Feature map (v1.0.0, explored in the running app and app/src)
- Link input for Spotify track, album, or playlist (playlists must be public); Load shows a preview list with covers, select all / per track.
- Quality 128/192/256/320 kbps; "Extra metadata (slower)" (Deezer/iTunes/MusicBrainz/LRCLIB gap-filling); output folder with Change... (native picker).
- Download with overall and per-track progress, log, Cancel; summary with failed tracks; Open folder.
- Output: MP3 named "Artist - Title.mp3", ID3 tags (title, artist, album, track, year, genre, Spotify IDs) and embedded cover.
- Shown in the demo: link, Load, 128 kbps, folder, Download, Open folder. Not shown: albums/playlists, Cancel, Change... dialog, Extra metadata toggle.
